# Changelog

All notable changes to `sloppytoppy` are documented here.

## 0.1.0 - 2026-11-12

- Initial terminal dashboard for Claude Code and Codex processes.
- Live CPU, memory, uptime, token, cache, and context-window telemetry.
- Guarded graceful and forceful process termination.
- Scriptable plain-text snapshots through `--once`.
